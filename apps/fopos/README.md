# FOPOS Module

FOPOS, OPUS Core üzerinde çalışan felsefe branş modülüdür. Bu paket mevcut
FOPOS uygulamasını değiştirmez; geçiş sırasında kullanılacak Module Contract
adaptörünü ve kanonik felsefe müfredatını barındırır.

İlk adaptör, FOPOS `v47` içindeki `2024.1` veri setinin dış kimliklerini
korur:

- 10 ve 11. sınıflar
- 15 ünite
- 22 öğrenme çıktısı
- sınıf başına 68, toplam 136 öğretim saati

Felsefeye özgü pedagojik ve AI kuralları bu pakette kalır. Kimlik doğrulama,
kullanıcı yönetimi, analitik, doğrulama ve doküman altyapısı Core
sorumluluğundadır.
